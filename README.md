## 🛠️ The Philosophy: "Drop-In Code"

Every repository you see on this profile follows a strict engineering rule: **Zero Framework Bloat.** 

Libraries like SFML are used strictly as a window frame to output the visuals. Every single calculation, loop, data structure, and system function is manually coded from scratch. This guarantees that the logic can be extracted and dropped directly into any other environment (custom engines, embedded devices, or larger desktop applications) seamlessly, provided there are no needs for dependencies on the environment.
