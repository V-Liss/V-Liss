## ⚙️ Core Technical Capabilities

Instead of relying on heavy third-party software packages, I design custom, low-level mechanics from the ground up:

* **Matrix & Grid Physics:** Custom 2D tracking systems that map layouts pixel-by-pixel to calculate lightning-fast movement, boundaries, and object interactions.
* **Vector Mechanics & Trajectories:** Instant path tracing (hitscan) and radial calculations to accurately simulate things like explosive impact radius, speed falloffs, and reflection angles.
* **State Management Engines:** Lightweight, menu-to-core system loops that cleanly switch between different modes of an application without memory leaks.
* **Peer-to-Peer Synchronization:** Fundamental socket networking allowing different systems to pass direct data arrays across local networks with minimal delay.

## 🛠️ The Philosophy: "Drop-In Code"

Every repository you see on this profile follows a strict engineering rule: **Zero Framework Bloat.** 

Libraries like SFML are used strictly as a window frame to output the visuals. Every single calculation, loop, data structure, and system function is manually coded from scratch. This guarantees that the logic can be extracted and dropped directly into any other environment (custom engines, embedded devices, or larger desktop applications) seamlessly, provided there are no needs for dependencies on the environment.
